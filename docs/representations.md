# 表示与坐标契约

## 基本约定

长度单位为米，时间单位为秒，旋转采用右手系。点采用列向量；`T_a_b` 表示从 b 坐标系变到 a 坐标系。世界坐标约定 x 向前、y 向左、z 向上；相机坐标约定 x 向右、y 向下、z 向前。数据适配通过显式坐标变换统一轴序。

相机安装标定 `T_rig_camera` 与自车轨迹 `T_world_rig(t)` 分开保存：

\[
T_{world,camera}(t,v)=T_{world,rig}(t)T_{rig,camera}(v).
\]

输入为同步、已校正到针孔模型的图像。鱼眼、畸变和滚动快门在数据适配阶段处理，并同步更新标定，使图像与针孔投影模型一致。

## 日志与共享证据

`DrivingLog.images` 为 `[T,V,3,H,W]`，使用线性 RGB、范围 `[0,1]`。真实相机编码值应先经过一致的颜色变换；跨相机曝光差作为预处理或训练增强处理。时间戳 `[T]` 严格递增。内参 `[V,3,3]` 使用原图像素坐标，安装外参 `[V,4,4]`，可选世界位姿 `[T,4,4]`。

编码器输出特征 `[T,V,h,w,F]`、光轴深度 `[T,V,h,w]`、相机系法线、语义和实例分配。光轴深度取相机坐标中的 z 分量。特征格中心对应原图坐标：

\[
u=(j+1/2)W/w-1/2,\qquad v=(i+1/2)H/h-1/2.
\]

同一整段日志中的实例槽具有稳定身份；槽数是容量上限。训练时进行轨迹级集合匹配，同一匹配结果贯穿整段时间。

`SceneEvidence.instance=0` 表示背景，正整数表示资产槽。语义依次为道路、其他静态背景、刚体、人体、天空、自车本体。静态背景聚合同时筛选背景实例标签和道路、其他静态背景语义。

## 规范刚体资产

当前刚体分支以车辆为实例，原点是固定包围体中心；x 为车头方向、y 为车体左侧、z 为上方。尺寸 `[length,width,height]` 在整个轨迹中固定，几何使用米制局部坐标。训练通过一致的规范朝向监督确定车头方向。

每个刚体资产保存规范高斯和固定尺寸，状态通过整体 SE(3) 变换 `T_world_rigid` 控制整体旋转和平移，车轮随车体整体运动。

\[
\mu^w=R\mu^a+t,\qquad\Sigma^w=R\Sigma^aR^\top.
\]

实现统一使用 `TokenKind.RIGID`、`RigidAsset`、`SimulationState.rigid_poses`、`WorldVault.rigids` 和 `TypedLatentCodec.rigid`，解码器权重键为 `rigid.*`。配置使用 `rigid_grid`、`rigid_motion`，查询规范为 `drivecompose-rigid-v2`；语义编号 2 表示刚体类别。仅支持新接口与新 checkpoint，不提供旧别名或权重键转换。

## 规范人体

`HumanTemplateProvider` 根据整条轨迹共享的体型码提供同拓扑模板：规范表面查询、绑定权重、父节点数组和 bind pose。

体型固定，关节动作逐帧变化。根位姿负责整体移动和朝向，根关节保持 bind pose 中的根变换。骨架全局矩阵始终位于人体根坐标中。骨架采用单根树，父节点排列在子节点之前。

对高斯 i，令规范骨架为 \(B_j\)，当前骨架为 \(P_j(q)\)：

\[
A_i(q)=\sum_jw_{ij}P_j(q)B_j^{-1},\quad
\mu_i^w=T_{world,root}A_i(q)\bar\mu_i.
\]

协方差由同一个局部线性部分 \(J_i\) 更新：\(\Sigma_i^w=J_i\bar\Sigma_iJ_i^\top\)。姿态检查筛除接近奇异的加权变换，由仿真后端限制或修正相应姿态。

人体采用骨架蒙皮，规范衣物体积由固定高斯表示。

## 结构潜码

每个查询包含规范位置 `[3]`、支撑单元尺度 `[3]`、类型、资产归属、参考世界位置 `[3]` 和局部注意力组。背景与刚体同时使用观测锚点和预留补全网格；人体使用完整规范支撑。天空查询编码为单位方向。

融合输入为 `[N,F+1]`：图像特征加有符号归一化深度残差。类型专属编码器输出 `[N,D]` 的共同宽度潜码。已观测标记、自由空间标记和置信度作为补全条件单独保存。

同一训练样本的部分观测和完整目标共享**同一查询布局**。完整目标在部分输入确定的查询上读取，保持 token 的位置、类型、顺序和归属逐一对应。

## 高斯与外观

`GaussianSet` 保存中心 `[N,3]`、对称正定协方差 `[N,3,3]`、不透明度 `[N]` 和方向外观 `[N,3,4]`。

外观采用固定局部方向的一阶模型：\(c(d)=\max(0,c_0+C\hat d_{local})\)。`direction_to_local` 将世界观察方向映回规范局部坐标，归一化后计算颜色，使资产旋转后的外观方向与几何保持一致。

天空采用 `[6,S,S,3]` 立方体贴图，面顺序和朝向由 `cube_directions` 显式定义。`sky_valid` 单独保存得到观测支持的天空方向，渲染后端据此判定天空有效域。天空颜色由观察方向确定。

## 固定内容与状态

`WorldVault` 中的数组复制并设为只读，资产映射按只读接口暴露。在线装配使用新数组保存变换结果，规范资产保持原值。`SimulationState` 中的活动资产映射确定本步渲染的资产集合。

构建种子记录一次补全选择；同一资产出现在不同 rollout 时使用同一份规范参数。当前状态提供在线装配所需的资产位姿与人体关节姿态。NPZ 持久化采用数组与 JSON 元数据，`allow_pickle=False`。世界格式版本为 2，刚体资产条目的 `kind` 为 `rigid`；加载器拒绝旧版本和旧资产类型，不自动迁移。
