# 评估与消融计划

## 评价对象

分别评价几何恢复、未见区域补全、跨状态资产一致性和闭环策略表现。图像、表面几何、碰撞几何与策略行为分别报告对应指标。

## 数据设置

- 场景内留相机/留时刻：评价观测附近的新视角。
- 轨迹外推：在预先定义的横向位移和姿态范围内评价新轨迹，单独报告超出世界支撑的像素比例。
- 资产环绕视角：评价车辆背面、车顶和人体背部，完整真值只来自完整采集或合成资产。
- 状态干预：给同一资产不同的车辆位姿、人体根位姿和关节姿态。
- 场景与身份外测试：划分采集路段和资产身份，避免记忆训练对象。

## 指标与审计

图像报告 PSNR、SSIM、感知距离及轮廓误差，按背景、车辆、人体、天空和未见区域分开统计。统一线性/显示颜色空间和曝光处理，再解释数值。感知指标实现和版本需在实验时记录。

具有完整真值的区域报告深度误差、表面距离、法线一致性和车辆尺寸误差。人体额外报告关节误差、绑定后的姿态一致性及脚底接触误差。观测一致性和结构有效性用于评价补全部分的约束满足情况。

固定世界的数值性质包括车辆点间距离不随位姿改变、旋转不改变刚体协方差特征值、bind pose 还原规范人体、规范资产在多次 rollout 后保持原值，以及同一状态组装结果与仿真计时无关。

有效域逐像素返回，结合背景几何支撑范围与单独保存的天空有效域进行判断。闭环评估定义低覆盖观测的处理方式，并报告完整轨迹集合及其中断比例。

## 关键消融

1. 联合补全与背景/资产独立补全：检查场景外观、尺度和接地一致性。
2. 移除三维观测锚点：检查薄结构和已见表面的保真。
3. 移除完整查询支撑：检查未见表面能否被实际生成。
4. 移除实例身份或规范化：检查跨帧重影与身份漂移。
5. 移除深度/遮挡门控：检查背景混入动态物体和资产纹理污染。
6. 移除已知自由空间和观测保护：检查新增高斯的错误遮挡。
7. 移除世界参考条件：检查局部资产与场景尺度、道路接触的关系。

## 构建检查与独立测试的区别

构建检查使用原观测视角，按视图限制绝对 RGB 误差、有效深度误差、覆盖率、相对退化和新增前景侵入；侵入比例按有效几何像素计算。检查阈值通过验证集标定。

独立测试使用与构建检查分离的视角、状态和场景。每条轨迹记录世界种子、表示版本、输入范围和物理代理版本，使不同策略共享同一个世界。
