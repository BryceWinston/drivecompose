# 设计选择

## 固定世界与轨迹复用

采用三维结构潜码联合补全，在离线构建阶段确定背景与规范资产。各条仿真轨迹复用同一份世界内容，通过当前状态控制资产放置与人体动作，使身份、几何和外观在轨迹之间保持一致。

## 轨迹级规范资产

背景与资产分别使用世界坐标和各自的规范坐标，身份形状与逐帧运动分开存储。车辆采用固定尺寸和整体刚体变换，人体采用固定体型、骨架绑定与逐帧姿态。轨迹级身份槽和集合匹配保持跨帧对应关系。

## 分类型表示与联合补全

背景、车辆和人体分别编码与解码，保留各自的几何结构。类型专属投影形成共同宽度潜码，共享补全网络交换道路、尺度、接地和外观条件。编码器、codec 与查询规范共同组成表示版本，并与补全网络绑定。

## 观测锚点与补全支撑

可靠观测锚点保留已见表面，有限背景网格、车辆局部网格和人体规范表面提供未见区域的生成支撑。每个查询预测多个高斯及其存在性，支撑分辨率和查询容量控制空间细节。

## 统一坐标与状态装配

资产头预测 rig 相对位姿，再通过 rig 世界变换得到资产世界位姿。人体根位姿控制整体移动与朝向，骨架控制局部姿态。高斯中心、协方差和方向外观使用同一局部变换，视觉资产与物理代理共享坐标和状态。

## 观测保护与有效域

可靠潜码在补全中保持固定，自由空间约束控制相应高斯的不透明度。观测检查结合绝对误差、逐视图覆盖率和新增前景侵入，背景支撑范围与天空有效域共同定义有效像素。完整目标用于条件流匹配训练，部分观测的真实日志用于渲染与观测约束适配。
