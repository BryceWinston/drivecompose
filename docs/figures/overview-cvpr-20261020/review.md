# 总览图科学与视觉自审

审查对象：`drivecompose-overview-native.svg` 及其 Edge 渲染的 PNG。审查类型为依据同一项目上下文的源码与视觉自审。

## 科学关系

已逐项核对以下关系：

1. 多相机日志经共享编码与证据形成背景、车辆、人体及天空查询；背景在世界坐标，车辆和人体在规范坐标，天空采用方向域。
2. 三个局部分组独立处理，通过全局记忆 gather / broadcast 交换信息；局部分组之间没有串行连接。
3. 条件流的每步投影保留观测潜码，并把自由空间潜码置零；解码阶段另将自由空间不透明度置零。
4. 三路解码先构成候选，再接受观测视图检查。图中 “Ref.” 合并表示原始观测与仅观测解码参考，具体含义写入图注。
5. 检查通过后才形成固定世界；候选到渲染器之间没有旁路，也没有画出自动修复 / 重新生成循环。
6. 运行时固定世界与当前状态分别输入组装渲染器。观测反馈经外部策略 / 动力学只更新状态。
7. 车辆采用整体刚体变换，人体采用关节姿态；状态区用轮廓与骨架表示，固定内容区用高斯表面表示。
8. 输入观测示意不使用代表“补全”的橙色。一个人体表示中只有一个骨架；蓝 / 橙表面属于同一人体。

## 视觉与结构核验

- 实际查看完整 PNG，核对主流程、核心区、参考输入、接受顺序及右侧状态反馈。
- SVG 画布 2400 × 1120；PNG 3600 × 1680。
- 51 个文本对象；最小字号 34 SVG px，按 178 mm 宽度折算约 7.15 pt。
- 浏览器实际字体渲染后的文本越界为 0，文本包围框相交为 0，结果见 `render-qa.json`。
- SVG 中没有 `<image>` 位图节点；场景、资产、潜码、算子与连线均为原生矢量对象。
- 蓝色已见、橙色补全、灰色未知、斜线自由空间；三类资产由行、标签与几何形状共同区分。
- 核心联合补全区域使用唯一的浅紫色大范围背景，阅读顺序为观测 → 规范查询 → 联合补全 → 接受后的世界 → 状态复用。

字号和文本检查用于捕获布局问题，科学拓扑仍由源码与实际图像核对。最终模板排版后需要再次检查物理字号。
