## 从四张参考图中采用的原则

1. 左上：堆叠驾驶帧、饱和蓝色主干、紫色机制区。新版用较大的输入帧和蓝 / 紫核心模块建立视觉重心。
2. 右上：不同载体区分特征、注意力、输出头与场景。新版用方格潜码、蓝色局部运算、紫色记忆和绿色解码头区分科学角色。
3. 左下：大范围阶段背景与专用连线走廊。新版由五列改为三个宽区域，把每步约束放到下方。
4. 右下：突出的完整三维场景与状态控制关系。新版扩大接受后的世界和输出视图，分开固定内容与外部状态输入。

只借鉴构图和视觉语法。未迁入参考图中的运动基、前后向因果注意力、视频扩散精修、深度 / 法向头、碰撞几何或逐场景优化。

## 为疏密关系做出的抽象

- 三类局部处理共同置于一个分组内，与全局记忆用一条组级双向关系表示；三行仍分别处理。
- 三类高斯解码以一个带三个类型端口的头分组表示；输出候选先接受观测检查。
- 外部策略 / 动力学作为 State 的来源，State 与固定世界分别输入渲染器。完整观测反馈回路留在已有详细数据流程图中。
- 流积分中的已见保持与自由空间约束独立置于底部，避免与主干争夺空间。
