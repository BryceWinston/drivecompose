## 主路径与约束

- `C, τ` 和当前潜码 `z^j` 分别进入局部处理；三类 token 的局部结果共同构成 `X̃`。
- 初始记忆 `M` 与 `X̃` 进入更新后的 `M′`；`M′` 和 `X̃` 的残差路径进入包含三类组件的 `U`。
- `U` 进入速度头；`Δτ u ⊙ vθ` 与 `z^j` 在加法节点汇合，随后经过 Projection 得到 `z^(j+1)`。
- 投影后的状态直接反馈到下一步的当前潜码；完成 `S` 步后输出 `z^S`。反馈线不指向记忆。
- 图例区分观测值保持、未知值更新和自由空间置零；上方的内部特征与记忆 token 不使用潜码状态纹理。

三行是代表性的背景、刚体和人体组件组；方法中的天空组和同类型的多个组没有逐一画出，不能把三行理解为模型只支持三个组。
