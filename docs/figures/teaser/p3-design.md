# P3：同一观测重建在新视角下暴露缺失

P3 延续已确认 P2 的资产身份、人物姿态与观测覆盖，只改变外部观察相机。当前[无文字素材](p3-geometry-concept.png)已改为几何覆盖示意，取消车内剖视，并按用户输入将人体正面标为未观测；用户确认后已放回 PPT 原图框。[覆盖示意提示词](p3-coverage-prompt.txt)、[包络修订提示词](p3-coverage-refinement-prompt.txt)、[人体正面修订提示词](p3-human-coverage-prompt.txt)和[生成记录](p3-coverage-generation-record.json)同时保存。

以下原有数值相机表、斜线面、小方洞和剖视方案均作为早期记录保留；当前方案见文末“几何覆盖与人体正面”一节，不能沿用旧掩码的数值核验声明。早期的 [p3-standalone.png](p3-standalone.png)已从 PPT 中替换，原文件保留作历史对照。

## 要表达的关系

多帧、多视角输入已经在 P2 中完成聚合，但仍存在所有输入都未覆盖的表面。P3 改变观察相机，让此前藏在车辆背面的未知侧面进入画面。缺失集合没有变化，变化的是它在目标视图中的可见性。

当前 P2 已明显展示车尾和地面的未知区域。因此 P3 的新增信息应落在车辆另一侧，不能把原有两个缺口重复展示当作新发现，也不能在 P3 临时新增缺口。

## 固定几何与显示

| 项目 | P2 | P3 |
| --- | --- | --- |
| 车辆、行人、道路、立面 | 原场景 | 相同世界坐标；车辆朝向和人物姿态不变 |
| 观察相机 | (-8,-14,7) | (-8,14,7) |
| 车辆近侧 -Y | 灰蓝已观测实面，带窗 | 被车体遮住，不把车窗复制到另一侧 |
| 车辆远侧 +Y | 藏在背面 | 白底、浅灰斜线和虚线轮廓表示未知范围 |
| 车尾 Uv、地面 Ug | 已存在的缺失 | 保留在同一世界位置，并随整体投影改变屏幕位置 |
| 车顶 | 灰蓝已观测面 | 保留，帮助识别同一资产 |
| 单面背景立面 | 展示观测正面 | 背向时仅画浅色位置轮廓，不虚构完整建筑或背面外观 |
| 补全色 | 无 | 无；橙金色保留给后续补全结果 |

预览对 P2/P3 使用同一正交投影比例和同一世界空间取景中心。换视角后，行人与地面缺口在屏幕上的左右位置可以改变；不要为保持画面左右顺序而单独移动对象。浅色斜线是未知范围的示意标记，不表示已经重建出一片有纹理的表面。

## 图内信息层级

- P3 仍保持当前宽高比约 2.35:1 的单场景素材；不再放一组输入、不再画方法框。
- 主体是车辆另一侧的大块未知区域；背景轮廓与车尾、地面缺口作为次要参照。
- 沿用 PPT 中已有相机变化图标与箭头，素材内部不重复放相机轨迹或说明文字。
- 标题可保留 `Unseen regions exposed`。图注对应短句可用：`A new camera view exposes missing surfaces in the aggregated reconstruction.`（新相机视角暴露了聚合重建中的缺失表面。）本轮只提出此句，没有改写论文图注。
- P6a 必须复用 P3 的相机、场景和人物姿态，仅将同一未知范围替换为补全内容，形成上下配对。

## 2026-11-03：基于新版 P2 的剖视候选（已弃用）

| 要素 | 旧表达的问题 | 新候选的处理 |
| --- | --- | --- |
| 远侧车身 | 在完整盒体上加一片斜线面，易被读为缺贴图 | 最近的远侧车身和轮胎不存在；保留车顶及更远的已观测侧壳，利用深度间隔显示一个开放的部分三维结构 |
| 车辆身份 | 方盒车与已确认 P2 的厢式车不一致 | 以新版 P2 为造型、材质、资产身份参考；旧 P3 只提供另一侧观察的大致方位 |
| 背景缺失 | 完整地台中只有小方洞 | 车后背景仍大范围缺失，在新视图中投向右侧，并延续到场景边界 |
| 人物和过街位置 | 独立摆放人物容易随意转身 | 以 P2 的同一走路瞬间和世界方向为设计约束，随相机变化呈现新的屏幕投影；不单独推进时间或修改人体动作 |

## 2026-11-03：几何覆盖与人体正面（当前候选）

当前 P3 表达“新视角暴露输入覆盖不足”，不模拟一个拆掉车门后可正常观察内部的货厢。已观测外部片段保留灰蓝实体感；未知内容在粗略三维支撑范围内以近白色覆盖与稀疏虚线表示。该范围不是已经补全的表面，也不表示确定为空的物理空间。

| 位置 | 被退回的表达 | 当前表达与原因 |
| --- | --- | --- |
| 车辆 | 从开口看到对侧外门把手、轮毂 | 取消内壁及内部外观；保留朝向当前相机的已观测车顶和前上方片段，其余以粗略未知包络表示 |
| 未知车体范围 | 精确轮拱轮廓、完整白车身或有材质感的白色实面 | 无门窗、轮拱和轮胎细节的浅色虚线包络；不把缺少观测的形状预先当作已知 |
| 背景 | 原立面正面细节重复出现在背面，逆面成为厚实白墙 | 同一位置的逆面仅保留很浅的轮廓；车后仍是连接到场景边界的大面积缺失 |
| 人体 | 新视角下完整紫色正面，暗示正面已有输入支持 | 依据用户指出的背面／后斜侧输入，头部、躯干及肢体的正面用近白色与淡虚线标未知，侧后缘保留少量紫色支持；不通过转身或换动作回避未知 |

人体模板提供粗略支撑与姿态，不等于输入已经观测了人体正面。这里不画真实空腔、解剖结构、裸露骨架或缺肢。车辆与背景的覆盖方案已获用户认可，最终一轮只针对人物进行局部生图修改；周边视觉保留，但不声称逐像素完全相同。

构图先使用[共同世界设定](../../../paper/build/teaser-p3-coverage/coverage-world.json)与[构建脚本](../../../paper/build/teaser-p3-coverage/build-coverage-guide.mjs)投影两个示意相机，得到 [P3 方位底图](../../../paper/build/teaser-p3-coverage/p3-coverage-guide.png)。底图将背向的已观测表面略去，是覆盖诊断的绘图约定，不是高斯渲染器默认背面剔除的假设。最终素材仍为 ImageGen 概念图，不声明与 P2 像素级配准或 Waymo 标定一致。

当前 PNG 为 1920×819、RGB。后续 P6a 应复用确认后的 P3 相机、人物姿态与支撑范围，再展示同一未知几何的补全，形成上下方法对照。
