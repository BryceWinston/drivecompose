# P4：联合补全后的场景与共享上下文

当前[素材](p4-joint-completion.png)使用新版 P2 的参考相机和姿态，将已确认 P2/P3 的未知支撑对应为连续的补全几何。包含墙体修订的版本已获用户确认，并放入原 PPT 的 P4 图框；其他图片和外部原生排版保留。

## 需要修复的具体问题

| 位置 | 原 P4 | 本轮候选 | 原因 |
| --- | --- | --- | --- |
| 车辆 | 方盒车，金色仅是平直车尾面 | 与新版 P2 同一类圆角短驾驶室厢式车；金色连接车尾、后角、短车顶续接与后下部结构 | 显示未知三维结构被补入，而不是对一个现成平面换色 |
| 背景 | 完整青色地台中的小金色方块 | 车后左侧原缺失区形成大范围、连续的金色道路延伸，与已观测青色路面齐平衔接 | 对应用户确认的大面积背景遮挡范围，不缩成装饰性小洞 |
| 墙体补充修订 | 上一版候选仍保留不规则左边界的灰色墙体片段，只有路面得到背景补全 | 沿同一立面补入连续金色墙体，连接顶部压沿、墙面和端部厚度；已观测灰墙及窗户保留 | 背景包含立面几何，不能只完成道路而留下断墙 |
| 人体 | 图标人物，未明确正面输入缺失 | 保留 P2 的三维人形、朝向与走路瞬间；已观测背部保持紫色 | 已完成的正面大部分在当前相机背向一侧，不通过转身或把背部涂金来强行展示 |
| 联合机制 | 三个组件经同一个上下文交互 | 保留同样的三条双向分支与一个共享条带，更新造型与材质 | 延续已认可的核心语义，不把图改成三个独立补全器 |

## 对应关系与图内文字

- P4 使用 P2 相机：车头朝右上，车尾朝左下；行人在车前方右侧，朝远侧路缘行走。
- 灰蓝车身、淡青已观测路面、浅灰已观测立面与紫色背面保持观测来源角色。新增墙段和道路、车尾一样用金色表示补全几何；金色是示意叠色，不是场景实际材质。
- 人体正面在此视角中大部分不可见。后续 P6a 若采用 P3 相机，才应显露同一人的正面补全，不能改变其世界姿态。
- 恰好四个图内标签：Background、Vehicle、Human、Shared scene context。三条颜色对应的双向分支都到达同一个上下文条带。
- 背景与演员在图面上的布局按 P2 约定维持，整幅场景为给共享上下文留白而统一取景；不声明逐像素或标定级对应。
