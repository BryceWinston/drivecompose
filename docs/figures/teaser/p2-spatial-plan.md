# P2 独立素材的空间设定

该设定服务于概念示意，坐标不来自 Waymo 标定。P2 是汇总后局部三维场景的外部观察视角；输入相机的采集视角另行固定。

| 要素 | 固定设定 |
| --- | --- |
| 道路与车辆 | X 为道路前进方向，车辆车头始终朝 +X；P2 中车头投影朝右上方。 |
| 行人 | 位于车头前方的斑马线处，固定在 (4.2, -1.5, 0)，朝 +Y 行走。P2/P3 保持同一姿态。 |
| 背景 | 道路另一侧一片已观测立面，固定在 y=3.8；不画成已经完整重建的建筑体。 |
| 输入观测 | 所有示意输入相机都在车辆前方 +X、近侧 -Y 的短轨迹内，可观测车头、近侧和车顶。 |
| P2 观察相机 | (-8, -14, 7)，正交后侧斜俯视；能看见已观测近侧、车顶和缺失的车尾面。它不是某一帧输入相机图。 |
| 车辆未知 Uv | 整个车尾面 x=-2，以及在 P2 中隐藏的远侧 +Y 面；不把车尾画成已有的蓝色实面。 |
| 背景未知 Ug | 车后地面 x∈[-3.7,-2.7]、y∈[0,0.7]。该区域在设定的输入轨迹内被车辆遮挡。白色、虚线和稀疏斜线表示未重建表面，不是物理坑洞。 |
| 后续 P3 | 相机改为 (-8, 14, 7)，车辆、行人、背景、未知区域均不移动；换角度后远侧未知面也被暴露。 |
| 后续 P4/P5 | 使用 P2 相机和同一场景，补入固定未知区域。车辆区域绑定车辆，地面区域绑定背景。 |
| 后续 P6a | 使用 P3 相机观察 P4 的补全场景，形成配对。 |

P2 只生成一张宽高比约 2.35:1 的无字场景素材。标题、图例、相机变化箭头与流程框由现有 PPT 提供。颜色沿用灰蓝车辆、淡紫人物、浅青地面和浅灰背景；橙金色留给后续补全内容。

完整数值与不变量见 [场景约定](p2-scene-contract.json)。几何底图与构建脚本位于 `paper/build/teaser-p2-standalone/`。底图用于约束 imagegen 的空间布局；最终生成图仍需目检，不能将其当作标定三维投影或实测可见性掩码。
