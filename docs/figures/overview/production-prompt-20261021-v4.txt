The one message is that a partial multi-camera driving log is first recovered and organized into background and canonical asset evidence, then completed with a conditional generative transformer, and finally decoded into persistent Gaussian components that can be assembled under changed states. The scientific authority is the following actual method. A visual encoder processes image patches with camera and time conditions. It estimates depth and other geometry, persistent actor identities, and time-varying actor states. These estimates allow motion-aware evidence aggregation on fixed queries: world-space background, local rigid-vehicle support, canonical-human surface support, and sky directions. Typed encoders map the aggregated evidence to a common code dimension. The completion model uses local attention inside each group and shared memory across groups. It predicts a conditional flow velocity for unknown codes. Each integration step retains observed codes and clears free-space codes. Typed decoders then create background, vehicle, and human Gaussians; a sky head gives background sky color. An original-view rendering check compares the complete candidate against the input images and an observed-only reference. Only a passed candidate becomes the reusable scene. At runtime, camera poses, vehicle rigid transforms, and human joint poses supply explicit state. These states drive composition and rendering of the same stored content.

Motion recovery belongs to the visual front end; controlled state changes belong to composition. The generator operates on the inferred scene layout, not on an unconstrained scene-layout synthesis branch. No extra actors are generated from a text prompt.
